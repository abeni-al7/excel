# Excel

This repository holds a single spreadsheet, `Product_IMG_00.xlsx`, and no code.

## Contents

| File | What it contains |
| --- | --- |
| `Product_IMG_00.xlsx` | A jewelry product image list with sheets for Earrings, Necklaces, Pendant, Ring, Baracelet (sic) and GROW. Rows pair product codes (for example `AN-5636`, `CR6496`) with links to product images (`.webp`) hosted on Amazon S3. |

## Use it

Open the workbook in Excel, LibreOffice Calc or any other spreadsheet application.
